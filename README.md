# Minecraft Mods

A repository for Minecraft mods, modding resources, and related projects.

## Getting Started

### Prerequisites
- Minecraft (Java Edition recommended)
- A mod loader (Forge, Fabric, Quilt, or NeoForge)
- Java Development Kit (JDK 17 or 21 depending on Minecraft version)

### Recommended Tools
- [IntelliJ IDEA](https://www.jetbrains.com/idea/) or VS Code
- [ModDevGradle](https://github.com/neoforged/ModDevGradle) or Fabric Loom
- [Minecraft Development](https://plugins.jetbrains.com/plugin/8327-minecraft-development) plugin for IntelliJ

## Structure

```
minecraft-mods/
├── mods/           # Individual mod projects
├── resources/      # Shared assets, textures, models
├── docs/           # Documentation and guides
└── templates/      # Starter templates for new mods
```

## Creating a New Mod

1. Choose your mod loader (Fabric is popular for simplicity)
2. Use a template from the `templates/` folder or generate one with [Fabric Template Generator](https://fabricmc.net/develop/template/)
3. Place your mod project under `mods/your-mod-name`
