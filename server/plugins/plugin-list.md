# Recommended Plugin List — DonutSMP Style Server

A practical list of plugins commonly used (or replicated) on DonutSMP-like servers in 2026.

> **Tip:** You can replace many individual plugins with an all-in-one solution like **UltimateDonutSMP** (free on SpigotMC / GitHub).

---

## 1. Core / Must-Have

| Plugin | Purpose | Notes |
|--------|---------|-------|
| **PlaceholderAPI** | Placeholders everywhere | Required by almost everything |
| **ProtocolLib** | Packet-level features | Required by many advanced plugins |
| **Vault** | Economy & permission bridge | Required |
| **LuckPerms** | Permissions & groups | Best in class |
| **spark** | Performance profiler | Highly recommended |

---

## 2. Economy & Selling

| Plugin | Purpose | Popular Options |
|--------|---------|-----------------|
| Economy Provider | Player balances | EssentialsX, UltraPAY, PerfPay, custom |
| Sell / Worth | `/sell`, item values, multipliers | DonutSell, PerfSell, Worth plugins |
| Shop | Admin / player shops | ShopGUI+, DeluxeMenus + custom, Rex Shop |

---

## 3. Player Systems

| Feature | Popular Plugins |
|---------|-----------------|
| Homes | DonutHomes, PerfHomes, HuskHomes, EssentialsX |
| Teams / Clans | DonutTeams, PerfTeams, SimpleClans, UltimateClans |
| TPA | Built into many cores, or dedicated TPA plugins |
| Private Messages | EssentialsX, or dedicated MSG plugins |
| Profiles / Settings | Often part of all-in-one cores |

---

## 4. Teleportation

| Feature | Notes |
|---------|-------|
| **RTP** (Random Teleport) | Very important for DonutSMP feel. Look for GUI + per-world radius |
| Warps | EssentialsX, or dedicated warp plugins |
| Spawn / AFK | Often handled by core or Multiverse |

---

## 5. Marketplace

| Feature | Popular Plugins |
|---------|-----------------|
| Auction House | DonutAH style, PerfAuctions, AuctionHouse |
| Player Orders | Order boards (buy/sell requests) |
| Billford / Rotating Trades | Special rotating NPC trades (common on DonutSMP replicas) |

---

## 6. PvP & Combat

| Feature | Notes |
|---------|-------|
| Combat Tag / Logger | Prevents combat logging |
| Safezones | Protect spawn / claim areas from PvP |
| Bounties | Place money on players |
| Duels / FFA | Optional but popular |

Popular: PerfCombat, BetterBounty, various duel plugins.

---

## 7. Crates & Rewards

- Virtual + physical crates
- Key system (`/keyall`, daily keys, etc.)
- Nice GUIs and animations

Popular options: DonutCrates, ExcellentCrates, CrazyCrates, or the crates module inside UltimateDonutSMP.

---

## 8. Staff & Moderation

| Feature | Plugins |
|---------|---------|
| Staff Mode + Vanish | Staff++ , or built into cores |
| Punishments | LiteBans, AdvancedBan, or core punishments |
| Reports / Helpop | Built-in or dedicated |
| Invsee / Enderchest see | Common in staff plugins |

---

## 9. Visuals & Quality of Life

- Scoreboard / Tablist (TAB, FeatherBoard, or core)
- Holograms (DecentHolograms, FancyHolograms)
- Cosmetics / Kill effects (optional)
- Chat formatting (LuckPerms + chat plugin or EssentialsX)

---

## 10. World & Protection

- Multiverse-Core (if multiple worlds)
- Claim / Protection (GriefPrevention, Lands, Residence, or core claims)
- World border / spawn protection

---

## Suggested Minimal Starter Stack

```
1. PlaceholderAPI
2. ProtocolLib
3. Vault
4. LuckPerms
5. Economy + Sell/Worth
6. Homes
7. Teams
8. RTP
9. Auction House
10. Crates
11. Combat Tag + Bounty
```

Or just install **UltimateDonutSMP** + PlaceholderAPI + ProtocolLib + LuckPerms + Vault.
